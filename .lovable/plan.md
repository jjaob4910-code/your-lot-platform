# Owners corporation service bento grid

## Goal
Replace the current three-column feature strip with a more visual bento grid inspired by the supplied reference, while keeping Your Lot’s own content and visual identity.

## Changes
- Keep the existing “Built to be easy. Priced to be fair.” introduction.
- Build a varied bento layout with large and small panels rather than equal feature cards.
- Show the practical services Your Lot provides: levy tracking, compliance reminders, maintenance coordination, shared records, committee access, and a single property overview.
- Use lightweight interface illustrations made from existing design-system elements, not copied artwork or fabricated property data.
- Rewrite the panel copy in plain, personal language that explains how each tool saves owners time and effort.
- Preserve the current semantic colours, typography, buttons, and responsive behaviour.

## Validation
- Check the section at desktop and mobile sizes.
- Confirm every panel remains readable, stacks cleanly, and contains no fake financial or property values.
