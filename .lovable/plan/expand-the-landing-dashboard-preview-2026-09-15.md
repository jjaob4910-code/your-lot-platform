# Expand the landing dashboard preview

## Goal
Make the dashboard preview feel richer and more immediately useful without inventing property data.

## Changes
- Keep the existing dashboard frame and personal “your property” language.
- Add four compact visual modules for calendar, meeting invite, levy status, and insurance renewal.
- Layer selected modules with restrained overlap, matching the supplied card-composition reference while preserving the current ivory-and-blue design.
- Use only empty or setup states, never fabricated totals, dates, progress, or charts.
- Preserve legibility and simplify the composition on mobile.

## Validation
- Check the landing page at desktop and mobile widths.
- Confirm no cards, labels, or icons overlap improperly and all empty states remain truthful.
